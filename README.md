# 🧹 Telegram Cleaner

Скрипт для полной зачистки Telegram-аккаунта перед удалением или сменой личности.
Удаляет сообщения, выходит из чатов, блокирует ботов, чистит профиль — всё из
одного меню в консоли. Написан на Telethon, работает через юзер-сессию.

## Что умеет

- 🗑 Удалять **все свои сообщения** во всех диалогах (пачками, чтобы не словить флуд)
- 🚪 Выходить из **всех** групп и каналов (свои собственные не трогает)
- 📢 Выходить только из **каналов** или только из **групп** (по отдельности)
- 🤖 Блокировать и удалять **всех ботов**
- 👥 Удалять **все контакты** одним запросом
- 🖼 Сносить **все аватарки** профиля
- ✏️ Очищать **bio** и удалять **username**
- 💬 Удалять **все личные чаты** (опционально — сразу блокировать собеседников)
- ⚡ Режим «сделать всё» — прогоняет все действия по очереди с паузами

## Особенности

- 💾 Сохраняет `api_id` / `api_hash` / телефон в локальный файл — вводить нужно один раз
- 🌐 Поддержка **системного прокси Windows** (читает из реестра) + ручной ввод `socks5://` / `http://`
- ⏱ Обработка `FloodWaitError` — если Telegram просит подождать, скрипт честно ждёт
- ⚙️ Настраиваемая задержка между запросами (по умолчанию 3 сек, минимум 2)
- 🔒 Работает локально, ничего никуда не отправляет, кроме запросов к самому Telegram
